# Astro на Bun

Пример приложения [Astro](https://astro.build/) на [Bun](https://bun.sh/) с серверным рендерингом (SSR).

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `4321` |
| Путь проверки состояния | `/` |

Railpack видит `bun.lock`: ставит зависимости через Bun, собирает проект (`bun run build`) и
запускает `bun run start`. Сервер собирается адаптером
[`@astrojs/node`](https://docs.astro.build/en/guides/integrations-guide/node/) в режиме
`standalone` и слушает `0.0.0.0` (`server.host: true` в `astro.config.mjs`). Порт берётся из
переменной окружения `PORT` — её передаёт платформа, — а без неё `4321`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
bun install

# запуск в режиме разработки
bun run dev

# сборка для продакшн
bun run build

# запуск собранного серверного приложения
bun run start
```
